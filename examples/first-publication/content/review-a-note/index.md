# Review a note before drawing a conclusion

Read the [[id:content:keep-the-context|original observation]] and ask which part you saw directly. A proposed explanation may fit that observation without being the only explanation that does.

Write down one question that would help you distinguish those explanations. The next useful action may be another observation, a comparison or a conversation, rather than a longer conclusion.
